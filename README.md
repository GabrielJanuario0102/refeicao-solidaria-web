# Refeição Solidária — Web

Projeto front-end do FIREFLYTECH, desenvolvido por etapas com React, TypeScript, Vite e Tailwind CSS.

## Como executar

Instale uma versão do Node compatível com o Vite utilizado. Na pasta do projeto:

```bash
npm install
npm run dev
```

Abra a URL indicada pelo Vite (normalmente `http://localhost:5173`). Para verificar a compilação:

```bash
npm run build
```

## Sprint 1 — REF-13

Rotas públicas: `/`, `/sobre`, `/como-funciona`.
Os links de login e cadastro levam a páginas informativas nesta sprint; os formulários e a sessão serão implementados na Sprint 2.
